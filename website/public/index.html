Computer time for seafarers

Watch Bells

A tiny Rust app that lives in your tray and rings traditional maritime watch bells every half hour.

Source Code Project Story

Cross-platform

Native binaries for macOS, Linux, and Windows. No Electron, no runtime dependency bloat.

Accurate schedule

Implements all seven watches including the historic Last Dog Watch pattern.

Quietly useful

Sits in your system tray, shows current watch and bell count, and supports muting when needed.
