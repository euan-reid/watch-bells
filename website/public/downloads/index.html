Installation notes

Unzip the macOS download and move Watch Bells to Applications. The same Mac download works on Apple silicon and Intel. Windows can run the downloaded executable directly. On Linux, mark the downloaded binary as executable before running it with chmod +x watch-bells-linux-*; the usual GTK 3, XCB, XKBCommon, ALSA, and xdo runtime libraries must be installed.
