Installation notes

macOS

Unzip the download, move Watch Bells to Applications, and open it. Look for the bell in your menu bar; there is no Dock icon. The same download works on Apple silicon and Intel Macs.

To start it automatically, add Watch Bells to Login Items in System Settings.

Windows

Keep the downloaded executable somewhere permanent and double-click it to run. Look for the bell in your system tray.

To start it automatically, press Windows + R, enter shell:startup, and place a shortcut to Watch Bells in that folder.

Linux

Choose the download that matches your processor. In a terminal, open the folder containing the download and make the file executable: 

chmod +x watch-bells-linux-x86_64

For ARM64, use watch-bells-linux-aarch64 instead. Run the file to start Watch Bells.

The app needs the GTK 3, XCB, XKBCommon, ALSA, and xdo runtime libraries. Install any missing libraries through your distribution's package manager.

To start it automatically, add the executable to your desktop environment's startup applications.
